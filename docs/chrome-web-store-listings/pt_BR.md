# Brazilian Portuguese Store Listing

Extension locale: `pt_BR`

## Name

Aprimorador de tabelas para GitHub

## Short Description

Uma extensão não oficial que facilita a leitura de tabelas largas nas visualizações de arquivos Markdown do GitHub.

## Detailed Description

Tabelas largas em Markdown no GitHub não deveriam transformar sua análise em um exercício de rolagem.

O Aprimorador de tabelas para GitHub adiciona controles compactos diretamente acima das tabelas nas páginas de visualização de arquivos Markdown. Mantenha sua posição, encontre as linhas importantes e copie o resultado sem editar o arquivo de origem.

Mantenha-se orientado

- Fixe as linhas de cabeçalho e as primeiras colunas enquanto rola a tabela.
- Salve padrões de fixação por repositório e título para as tabelas que você consulta com frequência.

Encontre o que importa

- Filtre linhas por texto ou expressão regular.
- Ordene por qualquer coluna ou oculte linhas e colunas desnecessárias.

Adapte a visualização à sua tarefa

- Ajuste a largura, quebre o texto ou redimensione as colunas para facilitar a leitura.
- Abra uma tabela no modo de foco em tela inteira quando precisar de mais espaço.

Leve com você apenas a parte útil

- Copie a visualização atual como Markdown, CSV ou TSV. O conteúdo oculto ou filtrado fica fora da cópia.
- Redefina as alterações temporárias sempre que quiser voltar à visualização original.

A extensão funciona somente nas páginas de visualização de arquivos Markdown do GitHub (`github.com/.../blob/...`). Ela não altera seus arquivos nem é executada em issues, pull requests, discussions ou páginas iniciais de repositórios.

Os padrões de fixação são armazenados localmente no Chrome. Nenhum dado do usuário é coletado, transmitido, vendido ou compartilhado.

O Aprimorador de tabelas para GitHub é um projeto independente e não é afiliado, patrocinado nem endossado pelo GitHub.
