# Simplified Chinese Store Listing

Extension locale: `zh_CN`

## Name

GitHub 表格增强器

## Short Description

一款非官方扩展，让 GitHub Markdown 文件预览中的宽表格更易于阅读。

## Detailed Description

宽大的 GitHub Markdown 表格不应让审阅变成反复横向滚动。

GitHub 表格增强器会在 Markdown 文件预览页的表格上方添加紧凑的控制栏。无需修改源文件，即可保持浏览位置、找到重要的行并复制结果。

保持方向感

- 滚动时冻结表头行和左侧列。
- 按仓库和标题保存常用表格的冻结默认设置。

找到重要内容

- 使用文本或正则表达式筛选行。
- 按任意列排序，或隐藏不需要的行和列。

根据任务调整视图

- 自动调整列宽、换行或拖动调整列宽，提升可读性。
- 需要更多空间时，在全窗口专注模式下打开单个表格。

带走有用内容

- 将当前可见视图复制为 Markdown、CSV 或 TSV；隐藏和筛选掉的内容不会包含在副本中。
- 随时重置临时更改，恢复原始视图。

本扩展仅在 GitHub Markdown 文件预览页（`github.com/.../blob/...`）运行。它不会修改文件，也不会在 Issue、Pull Request、Discussion 或仓库首页运行。

冻结默认设置仅存储在本地 Chrome 中。我们不会收集、传输、出售或共享任何用户数据。

GitHub 表格增强器是独立项目，与 GitHub 没有附属、赞助或认可关系。
