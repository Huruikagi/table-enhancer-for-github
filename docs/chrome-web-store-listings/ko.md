# Korean Store Listing

Extension locale: `ko`

## Name

GitHub 테이블 향상 도구

## Short Description

GitHub Markdown 파일 미리보기의 넓은 표를 더 쉽게 읽을 수 있게 해 주는 비공식 확장 프로그램입니다.

## Detailed Description

넓은 GitHub Markdown 표 때문에 검토가 가로 스크롤의 반복이 되어서는 안 됩니다.

GitHub 테이블 향상 도구는 Markdown 파일 미리보기 페이지의 표 바로 위에 간결한 컨트롤을 추가합니다. 원본 파일을 수정하지 않고도 위치를 유지하고, 중요한 행을 찾고, 결과를 복사할 수 있습니다.

위치 유지하기

- 스크롤하는 동안 머리글 행과 왼쪽 열을 고정합니다.
- 자주 확인하는 표의 고정 기본값을 저장소와 제목별로 저장합니다.

필요한 정보 찾기

- 텍스트 또는 정규식으로 행을 필터링합니다.
- 모든 열을 기준으로 정렬하거나 필요 없는 행과 열을 숨깁니다.

작업에 맞게 보기 조정하기

- 열 너비를 맞추거나, 내용을 줄 바꿈하거나, 열 크기를 직접 조정해 더 쉽게 읽습니다.
- 더 넓은 공간이 필요하면 하나의 표를 전체 창 집중 모드로 엽니다.

필요한 부분 가져가기

- 현재 보이는 내용을 Markdown, CSV 또는 TSV로 복사합니다. 숨기거나 필터링한 내용은 복사에서 제외됩니다.
- 원래 보기로 돌아가고 싶을 때 언제든 임시 변경 사항을 초기화합니다.

이 확장 프로그램은 GitHub Markdown 파일 미리보기 페이지(`github.com/.../blob/...`)에서만 작동합니다. 파일을 변경하지 않으며 Issue, Pull Request, Discussion 또는 저장소 첫 페이지에서는 실행되지 않습니다.

고정 기본값은 Chrome에 로컬로 저장됩니다. 사용자 데이터를 수집, 전송, 판매 또는 공유하지 않습니다.

GitHub 테이블 향상 도구는 독립 프로젝트이며 GitHub와 제휴 관계가 없고 GitHub의 후원이나 승인을 받지 않았습니다.
