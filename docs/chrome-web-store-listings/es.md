Extension locale: `es`

## Name

Mejorador de tablas para GitHub

## Short Description

Una extensión no oficial que facilita la lectura de tablas anchas en las vistas previas de archivos Markdown de GitHub.

## Detailed Description

Las tablas anchas de Markdown en GitHub no deberían convertir la revisión en un ejercicio de desplazamiento.

Mejorador de tablas para GitHub añade controles compactos justo encima de las tablas en las páginas de vista previa de archivos Markdown. Mantén tu posición, encuentra las filas importantes y copia el resultado sin editar el archivo de origen.

Mantén la orientación

- Fija las filas de encabezado y las primeras columnas mientras te desplazas.
- Guarda valores predeterminados de fijación por repositorio y encabezado para las tablas que consultas con frecuencia.

Encuentra lo importante

- Filtra filas por texto o expresión regular.
- Ordena por cualquier columna u oculta las filas y columnas que no necesitas.

Adapta la vista a tu tarea

- Ajusta el ancho, activa el ajuste de texto o cambia el tamaño de las columnas para facilitar la lectura.
- Abre una tabla en el modo de enfoque a pantalla completa cuando necesites más espacio.

Llévate solo la parte útil

- Copia la vista actual como Markdown, CSV o TSV. El contenido oculto o filtrado queda fuera de la copia.
- Restablece los cambios temporales siempre que quieras volver a la vista original.

La extensión funciona únicamente en las páginas de vista previa de archivos Markdown de GitHub (`github.com/.../blob/...`). No modifica tus archivos ni se ejecuta en issues, pull requests, discussions o páginas principales de repositorios.

Los valores predeterminados de fijación se almacenan localmente en Chrome. No se recopilan, transmiten, venden ni comparten datos del usuario.

Mejorador de tablas para GitHub es un proyecto independiente y no está afiliado, patrocinado ni respaldado por GitHub.
